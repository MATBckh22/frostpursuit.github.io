# Frost Pursuit 冰寒追霜

A project website for **Frost Pursuit**, an ultimate ice boat racing map built entirely in vanilla Minecraft.

🌐 **[Live Site here](https://matbckh22.github.io/frostpursuit.github.io/)**

## About the Map

Frost Pursuit is a 1k × 1k winter ice boat racing experience featuring:
- **7.5 Million Blocks** - Meticulously crafted terrain
- **Pure Vanilla** - No mods, no command blocks
- **Advanced Redstone** - Automatic timing, leaderboards, and display systems
- **Bilingual Support** - English and Traditional Chinese (繁體中文)

## Features

- 🏔️ **Map Showcase** - Isometric views and block statistics
- 📸 **Photo Gallery** - Day/night toggle with in-game screenshots
- ⚡ **Technical Documentation** - Detailed redstone system explanations
- 🌍 **Bilingual** - Full English and Traditional Chinese support

## Development

Built with React + TypeScript + Vite.

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
```
